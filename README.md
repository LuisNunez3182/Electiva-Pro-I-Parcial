## Ejercicios

| Punto | Archivo | Enunciado |
|-------|---------|-----------|
| 1 | [`punto1.py`](punto1.py) | Se tiene una lista de números enteros ingresados por el usuario. Desarrolle un programa que permita almacenar estos valores en una lista y luego muestre la suma total de los elementos, el número mayor y el número menor. |
| 2 | [`punto2.py`](punto2.py) | Se tiene una cadena de texto ingresada por el usuario. Desarrolle un programa que recorra la cadena como iterable y determine la cantidad total de caracteres, la cantidad de vocales (a, e, i, o, u) y la cantidad de consonantes. |
| 3 | [`punto3.py`](punto3.py) | Se tiene una lista de palabras ingresadas por el usuario. Desarrolle un programa que recorra la lista y cree una nueva lista que contenga únicamente las palabras cuya longitud sea mayor a 5 caracteres. Al final, muestre la nueva lista. |
| 4 | [`punto4.py`](punto4.py) | Se tiene una lista de números enteros. Desarrolle un programa que genere una nueva lista donde cada elemento sea el cuadrado del valor original. Luego, muestre la lista resultante. |
| 5 | [`punto5.py`](punto5.py) | Se desea registrar productos y sus precios utilizando un diccionario. El programa debe permitir ingresar al menos 3 productos con su respectivo precio. Luego, debe recorrer el diccionario y mostrar todos los productos con sus precios, el producto más costoso y el precio promedio de los productos. |

## Ejecución

Requiere Python 3. Cada punto es un programa independiente:

```bash
python3 punto1.py
```

## Indicaciones del parcial

- Grupos de mínimo cuatro (4) y máximo cinco (5) estudiantes.
- Cada integrante participa activamente en la solución del taller.
- Se realiza un video que explica el funcionamiento de cada algoritmo con diapositivas, diagramas de flujo o animaciones.
- Cada estudiante explica al menos uno de los ejercicios.
- El video se sube a YouTube (como no listado) o a Google Drive, con los permisos de visualización configurados.
- Solo un integrante del grupo envía la actividad.
